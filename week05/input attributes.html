Input Attributes Input elements use attributes to control how they behave and process user input. Understanding these attributes helps you create forms that work correctly and provide a good user experience. Important input attributes include: type – Defines the kind of input (text, email, password, etc.) name – The label that the value is sent under when the form is submitted (it does not have to be unique) id – A unique identifier on the page, used to connect a label to its input required – Makes a field mandatory to fill out placeholder – Shows example text inside an input field (it is not a substitute for a label) value – Sets a default value for the input field
